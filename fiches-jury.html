1Importer les candidats

Téléchargez sur l'extranet les exports « Liste des inscriptions » (UV1, UV2, UV3), puis sélectionnez-les ici, tous en même temps.

📂 Choisir les fichiers Excel

Le fichier est lu uniquement dans ce navigateur, il n'est envoyé nulle part. Le n° de licence, le club et les coordonnées ne sont ni affichés ni imprimés. L'adresse mail sert seulement au bouton « Résultat au candidat », le n° de licence seulement aux fichiers de résultats pour le site fédéral.

Le dan, les katas et le règlement (ancien ou nouveau) se règlent tout seuls d'après la colonne Catégorie. Les inscriptions annulées sont écartées.

2Renseigner la session

La date, le lieu et la signature apparaissent sur les fiches et dans les mails aux candidats.

Les durées de l'UV3-B se modifient directement dans chaque fiche (colonne « Durée max ») et valent pour toute la session, pour ce dan.

3Répartir les candidats sur les tables

Un clic répartit tous les candidats de façon équilibrée (nombre de tables dans les réglages ci-dessus). Vous pourrez changer la table d'un candidat à l'étape 2.

Répartir à nouveau tous les candidats sur les tables ? Les affectations actuelles seront remplacées.

4Accueil des candidats : liste corrigée (facultatif)

Corrigez à l'accueil les erreurs d'inscription (nom, prénom, année, uke, dan, UV, règlement) dans la fiche du candidat, à l'étape 2. Téléchargez ensuite la liste corrigée : importez-la sur votre téléphone avec « Choisir les fichiers Excel » pour y scanner les QR codes et créer les résultats.

Ce fichier contient les n° de licence et les adresses mail, nécessaires aux résultats et aux mails : gardez-le pour vous.

📷Scanner les fiches imprimées (facultatif)

Chaque fiche imprimée porte un QR code sous VALIDÉE et sous REFUSÉE. L'évaluateur entoure le bon ; vous le scannez et la décision s'enregistre ici.

Sur téléphone, ouvrez cette page dans le navigateur (version GitHub) après y avoir importé les listes. Vous pouvez aussi viser le QR avec l'appareil photo du téléphone : la page s'ouvre et enregistre la décision.

2Créer les fichiers pour le site fédéral

Un clic prépare les 3 fichiers « import_resultats » (UV1, UV2, UV3B). Cliquez ensuite sur chaque bouton « Télécharger », puis téléversez-les sur l'extranet.

3Prévenir les candidats

Dans le tableau ci-dessus, le bouton « ✉ Mail » de chaque ligne ouvre le mail de résultat du candidat (félicitations ou encouragements). Vous n'avez plus qu'à cliquer sur Envoyer.
